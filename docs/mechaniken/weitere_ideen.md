# Weitere Ideen aus der Studie (kurz)

- **Status:** Idee (Sammlung; einzelne Punkte bekommen bei Bedarf eine eigene Notiz)
- **Vorbild (nur Inspiration):** weitere Systeme aus Cyberpunk 2077, die in der
  Bereichsliste nicht standen. Nur Grundideen, nichts übernommen.

| Idee | Kurz | Bezug bei uns |
|---|---|---|
| **Herstellen** | Aus Schrott/Legierung Munition, Tränke, Aufsätze bauen | Material aus `waffenmods_guete.md`; Heiltränke bleiben vor allem kaufbar/findbar |
| **Unterschlupf** | Eigene Wohnung (Senke: Hütte, später Turmzimmer): Truhe, Kleidung wechseln, Schlafen = Zeit vergehen lassen, Trophäen | Ankerspiegel bleibt der Rastplatz; Unterschlupf nur Komfort und Geschichte |
| **Kopfgelder** | Gesuchte Verbrecher in der Stadt, Musterblick zeigt sie | Moral: festnehmen/übergeben statt töten |
| **Faustkampf-Turnier** | Arena in der Senke, Kämpfe ohne Waffen | testet Souls-Grundlagen, Geld, Ruf |
| **Rennen** | Straßenrennen (Motorrad), Steppenrennen (Steppenross) | Fahrzeuge |
| **Essen und Trinken** | Garküchen: kleine, kurze Stärkungen | Markt lebt; Respekt vor Speisevorschriften (Halal/Koscher-Stände im jeweiligen Viertel ganz normal) |
| **Nachrichten/Telefon** | Kontakte, Vermittler, Caspar-Mahnungen | `vermittler_auftraege.md` |
| **Gegner-Vielfalt** | Banden in der Senke, Netzwächter, Drohnen, Cyborg-Brecher | eigene Gegnerliste in einer späteren Studie |
| **Lebende Welt-Ereignisse** | kleine Zufallsereignisse: Überfall, Unfall, Streit | Moral, Ruf, Stadtvolk |
| **Barrierefreiheit** | Untertitel, Flackern reduzieren, Tastenbelegung ändern, Zielhilfe | Pausenmenü |
| **Schnellwahl-Rad** | Tränke, Wurfklingen, aktive Implantate, Hacks | viele Notizen fragen danach; eine gemeinsame UI-Entscheidung |
| **Tastenbelegung** | Neue Aktionen (Ducken, Nachladen, Scannen, Implantat, Fahrzeug rufen) | Gamepad ist fast voll → Doppelbelegung (tippen/halten) |

# Mechanik-Notizen

Eigene Designs, inspiriert von anderen Spielen. Entstehen mit dem Befehl
`/mechanik-studie <Mechanik 1>, <Mechanik 2>, …` (Claude im Terminal oder in der
Cloud). Vorlage: `VORLAGE.md`. Videos/Bilder als Vorlage dürfen in `vorlagen/`
liegen (nur zum Anschauen, nicht ins Spiel übernehmen).

## Mechanik-Studie 1 (gebaut)
`wucht.md`, `schubsprung.md`, `wandlauf.md`, `nachhall.md`, `fernzugriff.md`

**Abhängigkeiten (Reihenfolge beim Bauen):** Schleichgang (Sichtkegel,
`EnemyPerception`) vor Erledigen, Schattenhaut, Geräte/Kameras, Fahndung in
Stufen. Ducken-Taste gemeinsam für Gleitschritt und Schleichgang. Fahrzeuge vor
Verkehr, Rufen, Fahrzeugkampf, Radio. Detailstufen vor vielen Figuren, Regen,
Neon. Klangwelt vor Radio und Musik. Taste/Rad für aktive Implantate klären
(Schattenhaut, Zeitdehner, Armwerfer).
